# R26-CS-004 – Audixa
## Firewall Audit Analytics Platform

### Overview
Audixa is a research system for intelligent firewall log auditing with independent system components.

### Components
1. Log Classification Engine
2. Risk Scoring Engine
3. Compliance Analysis Engine
4. Recommendation Engine

### Team Branches
- `main` : final stable code (team leader only)
- `dev` : integration testing
- `it22156860` : Risk Scoring Engine
- `it22111692` : Recommendation Engine
- `it22167064` : Compliance Analysis Engine
- `it22231000` : Log Classification Engine

### Rules for Members
1. Do not push directly to `main`
2. Work only on your assigned branch
3. Pull latest `main` before starting
4. Work only in your assigned component folder
5. Create a Pull Request when ready
